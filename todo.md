Kanban Board

- local server implemented on Qt/C++ with data storage to SQLite and files in text MarkDown (MD)
- single-user mode for now.
- Qt client apps, suitable for both mouse/keyboard and finger touch interface, implemented with:
    - QtWidgets
    - QML, including Android, iOS and Linux.
    - WebUI on server
- Backlog(light-red), Work-In-Progress(WIP - light-yellow), Review (light-green) and Done(light-gray) panels.
